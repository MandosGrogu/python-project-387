# Тикет 001: Канонический формат спецификации

## Question

Какой формат спецификации является каноническим для раскладывания тикетов: OpenAPI, TypeSpec (main.tsp), markdown (docs/specification.md) или их комбинация?

## Blocked by

—

## Type

grilling

## Resolution

Канонический формат спецификации — OpenAPI (`docs/openapi.yaml`). TypeSpec и markdown не являются каноническими.
