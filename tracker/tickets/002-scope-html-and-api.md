# Тикет 002: Объём спецификации — HTML и API

## Question

Должна ли спецификация описывать только REST API, или также существующий HTML-интерфейс (Django-шаблоны)? Как они сосуществуют?

## Blocked by

—

## Type

grilling

## Resolution

Спецификация описывает только REST API. Существующий HTML-интерфейс (Django-шаблоны) в спецификацию не входит.
